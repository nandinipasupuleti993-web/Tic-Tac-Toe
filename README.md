
# Tic-Tac-Toe Game

## About the Project
A two-player Tic-Tac-Toe game developed using Core Java.

## Features
- Two-player gameplay
- 3x3 game board
- Player X and Player O
- Winner detection
- Draw detection
- Input validation

## Technologies Used
- Java
- Scanner class
- Arrays
- Loops
- Conditional statements
- Methods

## How to Run
1. Install the Java JDK.
2. Open the terminal in VS Code.
3. Compile the program:
   javac TicTacToe.java
4. Run the program:
   java TicTacToe
